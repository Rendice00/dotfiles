# Basic Requirements

* Git
* Vim
* Neovim
* Tmux
* Zsh
* Oh-my-posh
* Stow

## LSP python
```bash
sudo apt install python3-pylsp python3-pylsp-mypy python3-flake8 python3-mccabe python3-pycodestyle
```

## LSP C++
```bash
sudo apt install clangd
```

## Installation

```bash
git clone git@github.com:Rendice00/dotfiles.git
cd dotfiles
stow .
```
